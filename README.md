# Spokane Permit Sample

I pulled 20 records from the Spokane Accela permit portal for Roofing, Siding and Window, dated 01/01/2025 to 09/25/2025. 22 columns, no failures.

![Sample output](sample_preview.png)

The CSV is here along with the run log. The screenshot shows the same data as a table so it is easy to read, and the CSV opens directly in Google Sheets.

Across these 20 records the portal has 11 different Application Information fields. Not every permit has all of them, so I line the columns up across all records and leave a cell blank where a field does not apply. Licensed Professional comes from each record's own detail page.

The full date range is 2,277 records.
